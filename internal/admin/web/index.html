导入账号 JSON

用于迁移或恢复已有账号。首次使用可直接选择“添加授权账号”，无需准备文件。

从哪里获取账号 JSON？
  1. 已有 WorkBuddy2API 服务：从该服务的 auths 目录获取 workbuddy-<uid>.json。若修改过配置，请查看 auth_dir 指定的目录。
  2. 通过项目脚本登录：在已有源码环境中运行 ./login.sh，按提示完成浏览器授权，生成的文件位于 auths/workbuddy-<uid>.json。
  3. 只有 Docker 容器：在原服务所在主机执行下方命令，将凭证目录复制出来，再选择对应账号文件。
docker cp workbuddy2api:/app/auths ./workbuddy-auths

如容器名称或凭证路径已修改，请替换命令中的对应部分。把文件下载到当前电脑后上传，或粘贴文件的完整内容。

支持包含 auth / account 的嵌套格式，以及包含 accessToken、uid 的平铺格式。不要上传服务的 config.json。

账号文件含访问令牌，请只导入自己的账号，并妥善保管。

积分规则说明

            
×1.00 表示相对官方积分基准，×0.25 表示相对较低，并不代表每次请求固定扣 0.25 积分。实际消耗还取决于输入/输出 Token 和任务类型，官方没有公布统一的 Token 换算价格。

            
模型倍率缺失时显示“未知”；标记为 auto 的模型显示“动态”；数值 0 会保留，并结合返回的限免等活动标签展示。
